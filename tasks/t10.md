# t10: `ledger budget` — monthly per-category budgets in CNY
Extend the existing `ledger` CLI (package `ledger/`, stdlib only, unittest) with:
- `budget set <category> <amount_CNY> --month YYYY-MM`
- `budget list --month YYYY-MM`
- `budget check --month YYYY-MM`
Budgets are stored in budgets.json next to the data file (or `--budgets PATH`), written atomically like the other files.
`check` compares each budget with the month's EXPENSES in that category, converted to CNY with the existing per-entry dated-rate rule.
Keep all existing behaviour and tests working. See tasks/t10-acceptance.md for the exact contract.
